# Village Market Automations

Master copy of the Village Market (VM) automations. Separate from Gordon's (grodons/gordons-charlie).

- `apps-script/` - Google Apps Script code (runs in jeff@villagemarketatblue.com)
- `rules/` - copies of the Claude Rules Google Docs (the Docs in Drive are the live authority)
- `scheduled-tasks/` - the exact prompts and schedules of the Claude scheduled tasks
- `SETUP.md` - Jeff's one-time install steps
- `SYSTEM_MAP.md` - every ID, schedule and account (rebuild guide)
- `CHANGELOG.md` - dated list of changes

Built 2026-11-27: AP invoice processing (QBO bill entry sheets + renaming/filing), price-increase + margin alerts to Chrissan, labour control (hours budget) for Chrissan.
