# Operations Folder Guide

**Village Market** · Owner: Jeff Meakings · Last updated: November 27, 2026

Every file has one home. If you're not sure where something goes, use this table. If it still doesn't fit, ask Jeff instead of creating a new folder.

| Folder | What goes here |
|---|---|
| **00 Claude** | Automation rules, pricing and labour sheets. Don't move or rename anything here. |
| **01 Daily Counts & Logs** | Cash counts, tobacco counts, waste reports and other logs filled in every day or week. |
| **02 Instructions & Job Aids** | SOPs and how-to guides: scanning invoices, tobacco counts, pricing, close-out, OLG. |
| **03 Policies & Training** | Store policies (age-restricted sales, harassment, violence, health and safety) and training records. |
| **04 Health, Safety & Licences** | Fire plan, inspections (electrical, pest, forklift, scales), public health, AGCO liquor licence. |
| **05 Forms & Templates** | Blank forms to print: checklists, temp logs, incident reports, close-out form, letterhead. |
| **06 Inventory, Suppliers & POS** | Inventory counts and pricing, tobacco suppliers, Loblaws claim forms, POS instructions, Gordon's Grab and Go. |
| **07 Brand & Logos** | Logos and brand guidelines. Use these files only. Never redraw or stretch the logo. |
| **08 Village Association (BMVA)** | Blue Mountain Village Association papers. |
| **99 Archive** | Old, duplicate or out-of-date files kept for the record. Nothing is ever deleted - old versions come here instead. |

## Rules for filing

1. **Name files with the date first:** "YYMM DD Description", for example "2612 01 Fire Inspection.pdf". Newest files then sort together.
2. **One copy only.** Don't save the same file in two folders.
3. **Never put any of these in Operations:**
   - passwords or alarm/safe codes
   - pay, cheques or anything about staff pay
   - bank or card statements
   - staff personal information
   
   These belong only in Jeff's owner-only folder. If you find one here, tell Jeff.
4. **Invoices never go here.** Scan them with the "Invoice" preset (see SOP - Scanning Invoices). They file themselves.
5. **Don't create new top-level folders.** Use the closest folder above, or ask Jeff.
